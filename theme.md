# Визуальная тема для Telegram-бота

## Целевая аудитория
Пользователи, которые хотят организовать свои дела, отслеживать привычки и настроение. Целевая аудитория: молодые профессионалы, студенты, люди, ведущие активный образ жизни (18–35 лет).

## Концепция
Современный, минималистичный и дружелюбный стиль, который вызывает чувство порядка и мотивации. Тема вдохновлена трендами дизайна 2025 года: чистые линии, яркие акценты, мягкие градиенты.

## Цветовая палитра
- **Основной цвет (акцент):** #4A90E2 (глубокий синий) — для заголовков, кнопок, эмодзи.
- **Вторичный цвет:** #F5F7FA (светло-серый) — для фона сообщений (в промо-графике).
- **Дополнительный цвет:** #50C878 (мятный зеленый) — для успешных действий (например, ✅).
- **Ошибка/предупреждение:** #E94E77 (мягкий красный) — для сообщений об ошибках (например, ❌).
- **Нейтральный:** #333333 (темно-серый) — для основного текста.

Эта палитра создает баланс между профессионализмом и дружелюбностью, подходит для Telegram-интерфейса и промо-материалов.

## Шрифты
- **Основной шрифт:** Roboto (Regular, Medium, Bold) — чистый, современный, хорошо читаемый в Telegram.
- **Акцентный шрифт:** Montserrat (Bold) — для заголовков в промо-графике или названия бота.
- Telegram не поддерживает кастомные шрифты в сообщениях, поэтому используем Markdown (*жирный*, _курсив_) для выделения.

## Стиль сообщений
- **Форматирование:** Используем Markdown для единообразия:
  - Заголовки и ключевые слова — *жирный текст* (например, *Событие добавлено!*).
  - Акценты — эмодзи для визуального разделения (✅, ❌, 📋).
  - Списки — нумерованные или с символами (например, `-` для привычек).
- **Структура:** Каждое сообщение начинается с эмодзи, затем заголовок (*жирный*), затем детали.
- **Тон:** Дружелюбный, мотивирующий, но лаконичный.
